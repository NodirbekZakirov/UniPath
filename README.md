# UniPath

**UniPath** — сайт, который помогает абитуриенту подобрать университет. Пользователь вводит свои оценки, бюджет и специальность, а сайт показывает программы, отсортированные по соответствию этим данным, и объясняет, за что начислены баллы. Понравившиеся программы можно сохранить, а в калькуляторе посчитать все расходы на год учёбы.

## Возможности

- **Подбор программ** по IELTS, GPA, бюджету на обучение и специальности, с фильтром по стране.
- **Сортировка по соответствию** и постраничный вывод: по 6 программ на странице.
- **Страница программы** с требованиями, разбором баллов и ссылкой на официальный сайт.
- **Аккаунты:** регистрация, вход, выход и личный список сохранённых программ.
- **Калькулятор расходов:** обучение, жильё, питание, перелёты и стипендия за год.
- **Административная панель** для управления каталогом.

## Установка и запуск

Понадобятся **Python 3.10 или новее** и **Git**. Все команды выполняются в папке проекта, где лежит `manage.py`.

### 1. Скачайте проект

```bash
git clone https://github.com/NodirbekZakirov/UniPath.git
```

```bash
cd UniPath
```

### 2. Создайте виртуальное окружение

Виртуальное окружение хранит библиотеки проекта отдельно от остальной системы.

```bash
python -m venv .venv
```

Активируйте его одной из команд:

| Система | Команда |
|---|---|
| Windows, PowerShell | `.venv\Scripts\Activate.ps1` |
| Windows, CMD | `.venv\Scripts\activate.bat` |
| Linux, macOS | `source .venv/bin/activate` |

В Linux и macOS окружение обычно создаётся командой `python3 -m venv .venv`.

### 3. Установите зависимости

```bash
python -m pip install -r requirements.txt
```

### 4. Создайте таблицы базы данных

```bash
python manage.py migrate
```

### 5. Загрузите каталог программ

```bash
python manage.py seed_real
```

Команда добавляет семь программ реальных университетов. Повторный запуск обновляет эти записи и не создаёт дублей.

### 6. Запустите сайт

```bash
python manage.py runserver
```

Откройте **http://127.0.0.1:8000/**. Чтобы остановить сервер, нажмите **Ctrl+C**.

При следующем запуске достаточно активировать окружение и выполнить `python manage.py runserver`. Данные сохраняются в файле `db.sqlite3`.

Интерфейс рассчитан на компьютер: минимальная ширина страницы 1024 пикселя.

## Как устроен проект

Проект построен по обычной схеме Django. Вот что происходит, когда пользователь нажимает «Подобрать университеты»:

```text
Браузер отправляет запрос
  → unipath/urls.py            главный файл адресов передаёт запрос приложению
  → universities/urls.py       находит функцию для этого адреса
  → views.home                 управляет обработкой запроса
      → forms.SearchForm       проверяет введённые данные
      → matching.find_matches  берёт программы из базы и считает баллы
  → home.html                  шаблон собирает готовую страницу
Браузер показывает результат
```

За что отвечает каждая часть:

| Часть | Файл | Отвечает за |
|---|---|---|
| Модель | `models.py` | Какие данные хранятся в базе |
| Форма | `forms.py` | Какие данные можно ввести |
| Представление | `views.py` | Что делать при открытии страницы |
| Логика расчётов | `matching.py`, `costs.py` | Формулы; они не зависят от страниц и легко тестируются |
| Маршруты | `urls.py` | Какой адрес какую функцию запускает |
| Шаблон | `templates/` | Как страница выглядит в HTML |
| Стили | `static/css/` | Цвета, размеры и расположение |

В коде на каждой строке есть короткий комментарий о том, что она делает.

## База данных

Кроме стандартных таблиц Django, в проекте две собственные.

**`University`** — одна запись соответствует одной программе университета.

| Поле | Тип | Что хранит |
|---|---|---|
| `name` | Текст, до 120 символов | Название вуза и программы |
| `country`, `city` | Текст, до 60 символов | Страна и город |
| `major` | Выбор из списка | `cs`, `business` или `engineering` |
| `ielts` | Дробное, 0–9 | Минимальный IELTS |
| `gpa` | Дробное, 0–5 | Минимальный GPA по пятибалльной шкале |
| `tuition` | Целое, не меньше 0 | Обучение за год в USD |
| `scholarship` | Да или нет | Есть ли стипендии |
| `description` | Длинный текст | Описание и уточнения |
| `source_url` | Ссылка, можно пусто | Официальный источник |
| `verified_on` | Дата, можно пусто | Когда проверены данные |
| `is_demo` | Да или нет | Учебная запись или реальная |

**`SavedUniversity`** — связь «пользователь сохранил программу». Содержит ссылки `user` и `university`. Ограничение `UniqueConstraint` не даёт сохранить одну программу дважды. При удалении пользователя или программы связанные сохранения удаляются автоматически (`CASCADE`).

Профиль абитуриента и суммы калькулятора в отдельных таблицах не хранятся: они лежат в сессии посетителя.

## Как работает подбор

Каждая программа сравнивается с данными пользователя по четырём условиям:

| Условие | Баллы |
|---|---:|
| IELTS не ниже требования программы | 30 |
| GPA не ниже требования программы | 30 |
| Бюджет покрывает стоимость обучения | 20 |
| Специальность совпадает | 20 |
| **Максимум** | **100** |

- **Страна** не влияет на баллы: она только убирает из списка программы других стран.
- Остальные условия влияют только на баллы, поэтому программа с несовпадением остаётся в списке и показывает причину.
- **Сортировка:** сначала больше баллов, при равенстве по названию.

Пример для программы с требованиями IELTS 6.0, GPA 3.25, обучение $13 616, Computer Science:

| Условие | Абитуриент | Выполнено | Баллы |
|---|---|---|---:|
| IELTS | 6.5 | Да | 30 |
| GPA | 3.0 | Нет | 0 |
| Бюджет | $15 000 | Да | 20 |
| Специальность | Computer Science | Да | 20 |
| **Итого** | | | **70** |

**Баллы показывают совпадение с четырьмя условиями, а не вероятность поступления.** Дополнительные экзамены, секции IELTS, конкурс и требования к документам нужно проверять на сайте университета.

Код находится в [universities/matching.py](universities/matching.py).

## Калькулятор расходов

```text
Расходы  = обучение + (жильё + питание) × месяцы + перелёты
К оплате = расходы − min(стипендия, расходы)
Остаток  = общий бюджет − к оплате
```

- Обучение, перелёты и стипендия указываются за год, жильё и питание за месяц.
- Срок проживания: от 1 до 12 месяцев.
- Стипендия не может покрыть больше, чем сами расходы, поэтому сумма к оплате не бывает отрицательной.
- Отрицательный остаток означает нехватку денег, и страница показывает её сумму.

Пример: обучение $15 000, жильё $500, питание $300, перелёты $600, стипендия $2000, 12 месяцев, бюджет $25 000.

| Шаг | Расчёт | Итог |
|---|---|---:|
| Расходы | 15 000 + (500 + 300) × 12 + 600 | $25 200 |
| К оплате | 25 200 − 2000 | $23 200 |
| Остаток | 25 000 − 23 200 | $1800 |

В подборе бюджет относится только к обучению, а в калькуляторе ко всем расходам. Если открыть калькулятор со страницы программы, стоимость обучения подставится автоматически.

Код находится в [universities/costs.py](universities/costs.py).

## Административная панель

Создайте учётную запись администратора:

```bash
python manage.py createsuperuser
```

Панель открывается по адресу **http://127.0.0.1:8000/admin/**. В ней можно добавлять, редактировать и удалять программы, а также пользоваться поиском и фильтрами. Для реальной программы обязательно указать официальный источник и дату проверки. Обычная регистрация на сайте административных прав не даёт.

## Безопасность

- **Пароли** хранятся в виде хеша и проверяются стандартными средствами Django.
- **CSRF-токен** защищает все POST-формы от подделки запросов.
- **Изменения только через POST:** `require_POST` не даёт изменить избранное обычным переходом по ссылке.
- **Личные данные:** `login_required` закрывает страницы от гостей, а `filter(user=request.user)` показывает и удаляет только свои записи.
- **Проверка ввода на сервере:** формы отклоняют значения вне допустимых границ, даже если обойти проверки браузера.
- **Внешние ссылки** открываются с `rel="noopener noreferrer"`.

## Оформление (CSS)

Стили разделены на файлы, и страница загружает только те, что ей нужны.

| Файл | Где подключается |
|---|---|
| `base.css`, `components.css`, `layout.css` | На всех страницах, через `base.html` |
| `home.css` | Подбор |
| `program-card.css` | Подбор и сохранённые программы |
| `university.css` | Страница программы |
| `costs.css` | Калькулятор |
| `auth.css` | Вход и регистрация |

Каждая страница добавляет свои стили в блоке `{% block styles %}`. Сначала загружаются общие файлы, затем файл страницы: при равной силе селекторов действует правило, подключённое позже.

## Настройки через переменные окружения

Для локального запуска ничего настраивать не нужно. Переменные пригодятся при размещении на сервере:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `DJANGO_SECRET_KEY` | Учебный ключ | Секретный ключ; на сервере нужен собственный |
| `DJANGO_DEBUG` | `1` | `1` включает режим разработки; на сервере нужен `0` |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1,testserver` | Адреса, на которых работает сайт |

## Тесты и проверки

Запуск автоматических тестов:

```bash
python manage.py test
```

В проекте 19 тестов. Они проверяют расчёт баллов и расходов, проверку ввода, страницы, регистрацию и вход, доступ к избранному, CSRF и загрузку каталога. Тесты работают с отдельной временной базой и не затрагивают ваши данные.

Проверка конфигурации:

```bash
python manage.py check
```

Проверка, что все изменения моделей описаны миграциями:

```bash
python manage.py makemigrations --check --dry-run
```

## Частые проблемы

| Что случилось | Что сделать |
|---|---|
| `no such table` при открытии сайта | Выполните `python manage.py migrate` |
| Сайт открылся, но программ нет | Выполните `python manage.py seed_real` |
| PowerShell не даёт активировать окружение | Выполните `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторите активацию; настройка действует только для этого окна |
| `No module named 'django'` | Активируйте окружение и установите зависимости |
| Порт 8000 занят | Запустите на другом порту: `python manage.py runserver 8001` |
| `DisallowedHost` при открытии с другого устройства | Добавьте адрес компьютера в `DJANGO_ALLOWED_HOSTS` и запустите `python manage.py runserver 0.0.0.0:8000` |
