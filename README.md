# UniPath

Веб-приложение для абитуриентов: сравнение университетских программ по академическим требованиям, специальности и бюджету, сохранение интересных вариантов и расчёт годовых расходов на учёбу.

## Возможности

- Подбор по IELTS, GPA, стоимости обучения и специальности с фильтрацией по стране.
- Сортировка программ по соответствию введённым данным и постраничный вывод результатов.
- Подробная карточка с требованиями, объяснением баллов и ссылкой на официальный сайт.
- Регистрация, вход и персональный список сохранённых программ.
- Калькулятор расходов с учётом обучения, проживания, повседневных трат, перелётов и стипендии.
- Административная панель для управления программами университетов.

## Установка и запуск

Нужны Python 3.10 или новее и Git. Все команды выполняются из папки проекта, где находится `manage.py`.

### 1. Скачайте проект

```bash
git clone https://github.com/NodirbekZakirov/UniPath.git
```

```bash
cd UniPath
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
```

Активируйте его в **Windows CMD**:

```bat
.venv\Scripts\activate.bat
```

В **Linux / macOS** используйте `python3` для создания окружения, затем:

```bash
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
python -m pip install -r requirements.txt
```

### 4. Создайте таблицы базы данных

```bash
python manage.py migrate
```

### 5. Загрузите каталог программ

```bash
python manage.py seed_real
```

Команда добавляет семь программ реальных университетов. Повторный запуск обновляет эти записи без создания дубликатов.

### 6. Запустите сервер

```bash
python manage.py runserver
```

Откройте **http://127.0.0.1:8000/**. Для остановки сервера нажмите **Ctrl+C**.

При следующем запуске активируйте окружение и выполните `python manage.py runserver`. Данные сохраняются в `db.sqlite3`.

## Административная панель

Создайте учётную запись администратора:

```bash
python manage.py createsuperuser
```

Панель доступна по адресу **http://127.0.0.1:8000/admin/**.

Администратор может добавлять, редактировать и удалять программы, использовать поиск и фильтры. Для реальной записи необходимо указать официальный источник и дату проверки. Обычная регистрация на сайте не предоставляет административных прав.

## Как работает подбор

Программа сравнивается с профилем пользователя по четырём критериям:

| Выполненное условие | Баллы |
|---|---:|
| IELTS не ниже указанного порога | 30 |
| GPA не ниже числового ориентира программы | 30 |
| Обучение укладывается в бюджет | 20 |
| Специальность совпадает | 20 |
| **Максимальная оценка** | **100** |

Страна ограничивает выборку. Остальные критерии влияют на баллы: программа с несовпадением остаётся в результатах с соответствующим пояснением. При равной оценке результаты сортируются по названию.

**Баллы отражают соответствие четырём сравнениям, а не вероятность поступления.** Дополнительные экзамены, секции IELTS, конкурс и требования к документам проверяются по официальным условиям университета.

## Калькулятор расходов

Расчёт выполняется по формулам:

```text
Расходы = обучение + (жильё + повседневные траты) × месяцы + перелёты
К оплате = расходы − min(стипендия, расходы)
Остаток = общий бюджет − к оплате
```

Обучение, перелёты и стипендия указываются за год; жильё и повседневные траты — за месяц. Срок проживания составляет от 1 до 12 месяцев. Отрицательный остаток означает нехватку бюджета.

Бюджет в подборе относится к обучению, а бюджет калькулятора — ко всем расходам. При переходе из карточки стоимость обучения заполняется автоматически. Остальные суммы пользователь задаёт самостоятельно.

## Проверки

Проверка конфигурации:

```bash
python manage.py check
```

Запуск тестов:

```bash
python manage.py test
```

Проверка изменений моделей, не описанных миграциями:

```bash
python manage.py makemigrations --check --dry-run
```

В проекте 20 тестовых методов: расчёты, проверка ввода, страницы, регистрация, доступ к избранному, CSRF и загрузка каталога. Тесты используют отдельную временную базу данных.
