# UniPath

Веб-приложение для предварительного сравнения программ бакалавриата по IELTS, GPA, специальности и бюджету. Дополнительный калькулятор помогает оценить годовые расходы на обучение и проживание.

**Стек:** Python 3.10+ · Django 5.2.17 · SQLite · HTML · CSS.  
**Каталог:** 7 программ трёх реальных университетов; официальные источники проверены 22.10.2026.  
**Режим:** локальный запуск, интерфейс для компьютера.

## Возможности

- Подбор по IELTS, GPA, бюджету и специальности; фильтр по стране.
- Сортировка по оценке соответствия, по 6 программ на странице.
- Карточка программы с требованиями, объяснением баллов и официальной ссылкой.
- Регистрация, вход, выход и персональное избранное без дубликатов.
- Калькулятор: обучение, жильё, повседневные расходы, перелёты, стипендия и общий бюджет.
- Встроенная админка с поиском, фильтрами и редактированием записей.

## Быстрый запуск на Windows

Нужны установленный **Python 3.10 или новее** и интернет для первоначальной установки зависимостей. JavaScript, Node.js и отдельный сервер базы не требуются.

1. Распакуйте архив. Откройте папку `unipath`, в которой лежит `manage.py`.
2. В адресной строке Проводника введите `cmd` и нажмите Enter.
3. Выполняйте каждую команду отдельно.

Проверьте Python:

```bat
python --version
```

Должен появиться номер версии. Если выводится только `Python` или команда не найдена, установите Python с [python.org](https://www.python.org/downloads/windows/), включите **Add python.exe to PATH** и откройте CMD заново.

Создайте окружение:

```bat
python -m venv .venv
```

Установите зависимости:

```bat
.venv\Scripts\python -m pip install -r requirements.txt
```

Создайте таблицы:

```bat
.venv\Scripts\python manage.py migrate
```

Загрузите реальный каталог:

```bat
.venv\Scripts\python manage.py seed_real
```

Запустите сайт:

```bat
.venv\Scripts\python manage.py runserver
```

Откройте **http://127.0.0.1:8000/**. Терминал должен оставаться открытым. Остановка сервера — **Ctrl+C**.

Для следующего запуска достаточно последней команды. Пользователи и сохранения остаются в локальном файле `db.sqlite3`.

### Linux / macOS

Выполните те же шаги через `python3 -m venv .venv`, затем вместо `.venv\Scripts\python` используйте `.venv/bin/python`.

## Обновление установленного проекта

Если сайт уже настроен, повторно создавать окружение и пользователей не нужно.

1. Остановите сервер: **Ctrl+C**.
2. Сохраните резервную копию своей базы:

```bat
copy db.sqlite3 db.sqlite3.bak
```

3. Скопируйте содержимое новой папки `unipath` поверх прежней, подтвердив замену файлов. **Не удаляйте существующую папку проекта целиком.** Сохраните свою `.venv` и `db.sqlite3`: в архив они не включены.
4. Загрузите реальные программы и удалите стандартный старый набор вымышленных примеров:

```bat
.venv\Scripts\python manage.py seed_real --replace-demo
```

Флаг удаляет только известные названия старого набора с `is_demo=True` и пустым источником. Сохранения, связанные с удалёнными учебными карточками, также удаляются. Учётные записи, собственные записи и сохранения реальных программ сохраняются. Без флага старые примеры остаются.

5. Запустите сервер обычной командой. Обновите страницу через **Ctrl+F5**.

Новая схема базы не требуется. Команда `seed_demo` оставлена как совместимый псевдоним `seed_real` и больше не создаёт вымышленные программы. Повторная загрузка обновляет семь записей по паре «название + специальность» без дублей; ручные изменения именно этих записей будут заменены данными встроенного каталога.

Старый `DEFENSE_GUIDE.md`, если он остался после копирования, можно удалить: актуальный справочник — [PROJECT_GUIDE.txt](PROJECT_GUIDE.txt).

## Административная панель

Создайте администратора в отдельном окне CMD из папки с `manage.py`:

```bat
.venv\Scripts\python manage.py createsuperuser
```

Введите логин и пароль. Символы пароля в терминале не отображаются. Общей предустановленной учётной записи нет.

Адрес: **http://127.0.0.1:8000/admin/**.

Через админку можно добавлять, изменять и удалять программы. Для реальной записи снимите флаг «Учебный пример», укажите официальный источник и дату проверки. Форма админки проверяет заполнение этих полей. Обычная регистрация на сайте не предоставляет административных прав.

## Каталог и источники

| Университет | Страна | Программы в каталоге |
|---|---|---:|
| Nazarbayev University | Казахстан | 3 инженерные программы |
| University of South Dakota | США | Computer Science; Business Administration |
| Dakota State University | США | Computer Science; Business Administration |

Одна запись — одна программа. На её странице размещена ссылка **«Официальный сайт университета»** и дата проверки. Все страницы программ, приёмные требования и источники стоимости перечислены в [SOURCES.md](SOURCES.md).

Важные правила данных:

- Каталог — вручную проверенный срез на **22.10.2026**, без автоматического обновления.
- Все денежные поля выражены в **USD**. Для американских вузов используется опубликованная оценка **Tuition & Fees**: обучение и соответствующие сборы, без проживания; исключения указаны в описании.
- У американских вузов исходный академический вариант — **2.6/4**. Для сохранения прежней шкалы алгоритма записано **3.25/5 = 2.6 × 5 / 4**. Это условная пропорциональная нормализация, **не официальный перевод аттестата**. Исходная шкала видна в каждой карточке. Сервис не выполняет оценку эквивалентности иностранных документов.
- Записи NU относятся к платному **Regular Admission**. Конкурс на грант, альтернативные экзамены и условный приём имеют собственные правила.
- Общие требования первичного приёма не заменяют отдельные требования школы или конкретного набора. Секции IELTS и альтернативы GPA описаны текстом, но не оцениваются алгоритмом.

## Принцип расчёта

### Соответствие программе

| Критерий выполнен | Баллы |
|---|---:|
| IELTS не ниже указанного порога | 30 |
| GPA не ниже числового ориентира карточки | 30 |
| Стоимость обучения укладывается в бюджет | 20 |
| Специальность совпадает | 20 |
| Максимум | **100** |

Страна — отдельный фильтр. Остальные критерии влияют на баллы и не исключают программу автоматически. При равных баллах применяется сортировка по названию. Веса заданы в учебной модели и не обучены на решениях приёмных комиссий.

**Оценка показывает соответствие четырём сравнениям, а не вероятность поступления.** Окончательные условия определяет университет.

### Годовые расходы

```text
Всего = обучение + (жильё + повседневные расходы) × месяцы + перелёты
К оплате = всего − min(стипендия, всего)
Остаток = общий бюджет − к оплате
```

Срок проживания — 1–12 месяцев. Все суммы — целые USD. Если остаток отрицателен, показывается нехватка. Стипендия не уменьшает оплату ниже нуля.

Бюджет подбора относится к обучению; бюджет калькулятора — ко всем расходам. Начальные суммы калькулятора условные: замените их своими. Учитывайте только доступную для оплаты расходов часть стипендии. При переходе из карточки обучение подставляется автоматически. Последний корректный профиль и расходы запоминаются раздельно в сессии браузера.

## Структура проекта

| Путь | Назначение |
|---|---|
| `manage.py` | Команды Django |
| `unipath/` | Общие настройки, маршруты и WSGI |
| `universities/` | Модели, формы, обработчики, алгоритмы, админка и тесты |
| `universities/management/commands/seed_real.py` | Проверенные данные и команда их загрузки |
| `universities/migrations/` | Версии схемы базы |
| `templates/` | Страницы и повторяемые HTML-фрагменты |
| `static/style.css` | Существующее оформление для компьютера |
| `requirements.txt` | Зависимости |
| `SOURCES.md` | Происхождение и трактовка данных |
| `PROJECT_GUIDE.txt` | Папка → файлы → назначение → определения функций и методов |

Комментарии в Python, HTML и CSS объясняют действие строки и используемые конструкции. Разбор маршрута выхода, словарь методов и порядок изучения находятся в `PROJECT_GUIDE.txt`.

## Проверки

Проверка конфигурации:

```bat
.venv\Scripts\python manage.py check
```

Автоматические тесты:

```bat
.venv\Scripts\python manage.py test
```

Проверка отсутствия изменений моделей, не описанных миграциями:

```bat
.venv\Scripts\python manage.py makemigrations --check --dry-run
```

В проекте **20 тестовых методов**: расчёты, формы, страницы, регистрация, защита избранного, CSRF и загрузка реального каталога. Тесты создают отдельную временную базу и не изменяют вашу рабочую базу.

## Настройки и ограничения

- Прямые зависимости устанавливаются через `requirements.txt`; код Django не скопирован в проект.
- `.venv`, `db.sqlite3`, резервные копии базы, `.env` и кеш Python исключены из Git. Каталог восстанавливается командой `seed_real`, таблицы — командой `migrate`.
- Собственного автоматического сбора данных, валютного пересчёта, прогнозирования поступления и проверки всех приёмных условий нет.
- Конфигурация по умолчанию предназначена для локальной демонстрации: `DEBUG` включён, ключ учебный. Для публичного размещения задайте `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS`, настройте HTTPS и раздачу статики. `runserver` — сервер разработки.
- Загрузка исходников на GitHub сохраняет код; для работающей публичной ссылки требуется отдельное развёртывание Django.
